# 原应用运行观察与截图计划

本仓库尚未取得原App截图。要把静态规格推进到“完整复刻并且与原版一致”，需要在有可用原应用、账号与功能环境时补充本文件的状态。该计划是后续验证步骤，不代表已经完成。

## 固定记录

每次记录版本、平台、窗口CSS尺寸、显示缩放、主题偏好、字体开关、账户/连接类型、功能开关、前置操作、实际结果。遮蔽个人账号、私有消息和凭据；用测试Bot与示例文件。截图名建议 `0681-light-chat-idle-1280x800.png`。动效另记录短视频/时间序列，截图不能验证动画顺序。

## 必须补齐的画面和行为

| 区域 | 状态 / 操作 | 核对点 |
|---|---|---|
| 主窗口 | 首次启动、登录前/后、空聊天、长消息、搜索定位 | 默认页面、标题栏/留白、实际字体、滚动和焦点 |
| 侧边栏 | 展开/折叠、拖宽、拖过折叠阈值、窄后再变宽 | 保留展开偏好、列表密度、未读/置顶/分区 |
| Composer | 空/文字/多行/IME/菜单/只读；6附件与第7个；发送成功/失败 | 动作切换、输入高度、禁用/清空/失败保留 |
| 语音 | 激活、录制、停止、处理、取消、权限失败 | 顺序、反馈、按钮/波形、草稿保留 |
| 消息 | 排队、发送、运行、待确认、完成、失败、重试/取消 | 状态卡、动作菜单、时间与消息分组 |
| 正文资源 | 图片、文件、富文本、代码、公式、链接、PDF/媒体预览 | 字体、选择/复制、溢出、弹层 |
| 详情 | overview/media/computer/members与对象切换 | tab条件、宽度保存、任务/详情互斥 |
| 任务线程 | 主区847/848/849宽；切并排、关闭、返回、独立输入 | 测量区域、宽度公式、taskId回复上下文 |
| 设置 | 4导航、usage可见/隐藏、主题系统变化、字体开关 | 真正生效条件、字段反馈、持久化与重开 |
| 电脑/教学 | 连接前/后、重建/断线、教学录制/取消/回放 | 真实入口、状态和宿主边界 |
| 浮动板 | 收起、展开、拖动4px阈值、3附件、第4附件、菜单快捷键 | 独立窗口外观、44–140输入高度与发送回收 |
| 快捷键 | 规格列出的18项；菜单占焦点；输入法；Ctrl+Tab松Ctrl | 宿主冲突、动作目标、未误发送 |
| 可访问性 | Tab/ShiftTab、Escape、缩放、减少动画、高对比 | 可见焦点、关闭回焦、可操作性 |

浅/深主题至少各一套。线程测试使用**主内容区宽度**而非整窗宽。先保存原版观察，再按 [83项验收清单](replication-checklist.md) 验证目标项目；清单默认全部未勾选。

## 当前未知项

原版默认字体开关、登录/账户页面、所有feature gates、动态内容、音频事件完整映射、电脑/教学完整流程、各平台菜单快捷键冲突、浮动板真实像素和完整动效尚未知。源码中可发现组件不代表默认界面同时显示。原打包代码当前不能直接在浏览器独立运行。
